# lineup-app

This application provides a process for managing class proposals through various stages, from initial consideration to final evaluation. It starts with a proposal that can either be rejected, accepted, or moved into development. If rejected, the proposal is marked as "Dead." If accepted, the class progresses through stages such as "Approved," "Slated," "Offered," "Confirmed," "Published," "Listed" and "Running." During its lifecycle, the class can be declined, defered, canceled or discontinued at different stages. Throughout the process, there are opportunities for a class to be revised. Ultimately, the application ensures that classes are carefully managed and transition through multiple states based on appropriate actions taken along the way.
